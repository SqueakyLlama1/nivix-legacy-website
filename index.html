What will happen to my existing Nivix Studio products?

What if I don't update?

Nivix Studio products should work just fine until an OS update breaks them. But we strongly recommend updating to get the latest security and features.

*WE WILL NOT BE DEVELOPING OR RELEASING ANY UPDATES FOR NIVIX STUDIO PRODUCTS. IN ORDER TO KEEP RECEIVING UPDATES, PLEASE INSTALL THE LATEST NIVIX STUDIO PRODUCT UPDATES.

Update popups within Nivix Studio products will no longer popup when the update servers are put out of commission in July, 2027. To obtain updates for the apps after that is put into effect, you must get an installer from the Playpen Software Website. All your data will stay in tact.
